# Website

The marketing site for SonicBrief, served from GitHub Pages at
<https://nestchao.github.io/SonicBrief/>.

Plain HTML, hand-written CSS and three ES modules. No framework, no build step,
no `node_modules`: what is in this folder is what gets deployed.

## Preview locally

```powershell
python -m http.server 8000 --directory site
# then open http://127.0.0.1:8000/
```

A server is required rather than `file://` because the Chinese overlay is
fetched from `assets/i18n/zh.json` at runtime.

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | The landing page. English copy lives here, inline. |
| `licenses.html` | MIT / GPL-3.0 summary and the third-party pointer. |
| `404.html` | Served by GitHub Pages for unknown paths. |
| `assets/css/styles.css` | The whole design system, in cascade layers. |
| `assets/js/app.js` | Nav, tabs, reveals, copy buttons, the sample switcher. |
| `assets/js/i18n.js` | Language toggle and the Chinese overlay. |
| `assets/js/github.js` | Star count and live download links, best effort. |
| `assets/js/demo-data.js` | Sample transcript summaries, three styles × two languages. |
| `assets/i18n/zh.json` | Simplified Chinese for every `data-i18n` key. |
| `assets/img`, `assets/fonts` | Generated by `scripts/build_site_assets.py`. |

## Translating

English is the source of truth and stays in the HTML, so the page is indexable
and works without JavaScript. Any element that needs translating carries a key:

```html
<h2 data-i18n="feat.title">Small app, sharp edges.</h2>
<meta data-i18n="meta.description" data-i18n-attr="content" content="…">
```

Add the same key to `assets/i18n/zh.json` with the Chinese string. Values may
contain inline markup (`<em>`, `<strong>`, `<span class="cite">`), which is
inserted through a template that strips scripts and event handlers.

`node scripts/check_site.mjs` fails if a key is missing from `zh.json` or if
`zh.json` has a key the markup no longer uses.

## Regenerating images

Screenshots are captured by hand and committed under `docs/`, never edited in
place. Rebuild the web versions with:

```powershell
python scripts/build_site_assets.py            # everything
python scripts/build_site_assets.py --only desktop
python scripts/build_site_assets.py --only og   # social card
```

The crop box for desktop captures is a constant (`DESKTOP_CROP`) so a re-shoot
only needs the new file dropped into `docs/desktop/`.

## Checks

```powershell
node scripts/check_site.mjs
```

Verifies local links, anchors, image dimensions and alts, JSON-LD, the sitemap,
translation coverage and the size budgets. The same command runs in CI before
the Pages upload.

## Deploying

`.github/workflows/pages.yml` uploads this folder on every push to `main` that
touches `site/`. GitHub Pages serves it as a *project* site, so every internal
URL must stay relative — `assets/…`, never `/assets/…`.
